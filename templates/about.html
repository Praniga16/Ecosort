EcoSort AI Project Overview

Real-Time Waste Segregation System Using CNN and Transfer Learning with MobileNetV2.

How It Works

End-to-end computer vision pipeline from input image to disposal recommendation.

01
Capture
Upload or snapshot waste image via browser camera.
02
Preprocess
Validate format, convert to RGB, resize to 224x224.
03
Analyze
Extract deep feature maps using MobileNetV2 base.
04
Classify
Compute Softmax probabilities for 6 waste categories.
05
Recommend
Output confidence rating and actionable recycling advice.

Problem Statement

Rapid urban growth has led to massive solid waste accumulation. Improper waste segregation at the source leads to recyclable materials filling up landfills, causing environmental degradation, toxic pollution, and economic loss. Manual sorting is slow, unsafe, and prone to human error.

The AI Solution

EcoSort AI leverages Deep Learning and Transfer Learning with MobileNetV2 pretrained on ImageNet to automate real-time waste classification into six primary classes. By combining high accuracy, low latency inference, and an intuitive web UI, it provides immediate disposal guidance.

Machine Learning Architecture & Dataset

MobileNetV2 Transfer Learning

  • Base Network: MobileNetV2 pretrained on ImageNet (inverted residual bottleneck architecture).
  • Input Resolution: 224 × 224 × 3 RGB pixels.
  • Data Augmentation: Random horizontal flip, rotation (20%), zoom (20%), and contrast adjustment.
  • Custom Head: GlobalAveragePooling2D → Dropout (0.3) → Dense (128, ReLU) → Dropout (0.2) → Softmax (6 classes).
  • Optimizer: Adam (lr = 0.001 feature extraction, lr = 1e-5 fine-tuning).
